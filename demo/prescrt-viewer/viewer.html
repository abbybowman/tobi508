TOBI demo viewer: SCRT and pre-SCRT files

This page is TOBI's demonstration viewer, built from the "View Report" page of DHS's SCRT (MIT licence). It is not DHS's tool, and it only displays files: it does not edit or save them. A pre-SCRT file is an agent-assisted record written by TOBI. An SCRT file is the record a person saves in SCRT.

Tool tips

  1. Choose a report file. It can be an SCRT file or a pre-SCRT file.
  2. Optionally choose a second file to compare with. Its result and comment appear beside each test, matched by test ID, and rows where the two results differ are marked.
  3. Expand the Product, Testing Information and Test Environment sections to see more.
  4. Select a screenshot to see it larger. Press Escape to close it.
