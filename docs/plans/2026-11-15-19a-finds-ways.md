## PR 1: a suspected alias of T (19.A 1.10.0)

### Terms (new entries, after *T*)

- *Suspected alias* (1.10.0; Abby, 2026-11-14 and 2026-11-15: a tester
  treats `/cilab/index.html` as `/cilab/`; round 2 p05): the destination
  of a link on another page the test read (a caller's page, a suggested
  page, a search results page) that is not T but differs from T only in
  one or more of these ways: its last path segment is a file named
  `index.*` or `default.*` where T's path ends in `/`, or the reverse; its
  scheme (`http`, `https`); a leading `www.` on the host. Any other
  difference (another directory, file name, host or query string) is not
  an alias. A link on T itself is not counted: a link from T to T is no
  way to reach it.
- *Alias check* (1.10.0): only while fewer than two kinds are found and a
  suspected alias exists. At most 3 a run, in the order their links are
  read. Each is loaded exactly as a caller's other page is loaded, by the
  same code: the allowlist on every redirect hop, T's host before and
  after redirects, its own HAR, the page cache, the 20 s share a
  caller-named page gets. It is *the same page as T* (a *verified alias*)
  when its final address equals T's (fragment and trailing slash aside),
  or its recorded document is byte for byte T's (`document_sha`, K-01).
  It is *not verified* in every other case: loaded with other bytes
  (a server that changes its page on every load, or another page),
  not loaded (not allowed, another host after redirects, no recording in
  replay mode, an error, out of time), or past the 3 checked. Its own
  links are never read or followed.
- *Leads to T* (amended): a link leads to T when its destination equals T
  or a verified alias of T (absolute, fragment dropped, trailing slash
  ignored).

## PR 2: the suggested pages, checked one by one (19.A 1.11.0)

### Terms, *Suggested pages* (replaces the entry)

- *Suggested pages* (1.11.0; Abby, 2026-11-14 and 2026-11-15: a tester
  goes down to a child page for a breadcrumb or a link back, up to the
  parent, and to the home page): pages of T's host that could show more
  ways, at most 5:
  1. *the site map*: the first link on the pages read named "site map",
     "sitemap" or "A-Z index";
  2. *T's parent*: the address one level up from T's own path, on T's
     host (`/a/b/c/` and `/a/b/c.html` give `/a/b/`; `/a/b/index.html`
     gives `/a/`; T at the root has none). It comes from T's address, not
     from page content;
  3. and 4. *child pages*: the first 2 links on T, in reading order, on
     T's host, whose path is under T's own directory (T's path when it
     ends in `/`, else its path up to the last `/`) and is not T, that
     directory, or a suspected alias of T; links to files that are not
     pages (an extension other than none, `html`, `htm`, `shtml`, `php`,
     `asp`, `aspx`, `jsp`, `cfm`) are left out. A T whose directory is the
     site root has no child pages (every page of the site is under it);
  5. *the home page*: the site's root on T's host.

  A page already given, T, a suspected alias of T and the same address
  twice are left out. Breadcrumbs are read on the pages that are checked,
  as any link to T is; they are not suggested on their own.
- *Checking the suggested pages* (1.11.0; P1 = A): only while fewer than
  two kinds are found after the caller's pages and the alias check. In
  the order above, one at a time; each is loaded exactly as a caller's
  other page is loaded (the same code and limits as the alias check),
  read as another page (W1, and the alias check for the links it shows),
  and the test stops as soon as two kinds are found. Then, still fewer
  than two, the live search (unchanged: Abby, 2026-11-02, the pages
  first, then the search). In all, at most 5 suggested pages, 3 aliases
  and 2 searches a run. The tool never follows any other link it reads.
  A suggested page that cannot be loaded or read is *not checked*.
